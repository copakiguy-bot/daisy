토큰은 어디서 받나요?
깃허브 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
Repository access 에서 daisy 를 고르고, Permissions → Repository permissions → Contents: Read and write. 만들어진 토큰(github_pat_…)을 위 칸에 넣으세요.
토큰은 이 브라우저에만 저장되고 데이지 화면이나 저장소에는 올라가지 않습니다.
